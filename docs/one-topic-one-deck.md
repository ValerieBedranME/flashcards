# Одна тема — один набор

Пользователь прямо разрешил реализацию. В интерфейсе остаётся одна сущность «Тема»: создание по предмету и одному названию, редактирование, изучение и публикация всей темы. Отдельное поле «Название набора» убрано; раздел называется «Мои темы».

Существующие подборки и независимые копии становятся отдельными темами в интерфейсе. Они не сливаются по прежнему общему разделу или совпадающему имени. Старые внутренние ID, карточки, авторство, публикации и SRS не преобразуются. Область занятия фильтруется по ID конкретной подборки; старый API общего раздела остаётся совместимым.

В Google Sheets пользователь заполняет одну колонку «Тема», вопрос и ответ. Прежняя колонка «Набор» скрывается при синхронизации, а не удаляется: старые таблицы, служебные ID и незавершённые задания сохраняют совместимость. При одинаковом названии нескольких личных тем импорт просит различить названия. Переименование выполняется в приложении и отражается в видимой колонке таблицы.

Проверки: отдельный выбор двух старых подборок общего раздела; отсутствие изменений карточек и SRS; создание с одним названием; импорт строки без второй колонки названия; сохранение исходного автора копии; неоднозначное имя не выбирается молча; браузерная проверка формы и рабочего сайта после публикации.

Объединение файлов предметов в один Google-файл — отдельная ранее согласованная доработка, в этот выпуск не входит.

Локально прошли 58 проверок (62 обнаружено, 4 PostgreSQL пропущены без подключения); проверен синтаксис JavaScript. В браузере создана тема «Кости» с одним названием, добавлена карточка и запущено занятие через предмет и тему. Старые тестовые файлы /tmp отсутствовали, поэтому использована новая изолированная среда без рабочих данных и Google-токенов. В этом прогоне прежние PostgreSQL и OAuth-проверки не выдаются за выполненные повторно.
