# Изображения и анимация — состояние реализации 14 сентября 2026

Пользователь согласовал макет, весь план реализации, проверки и публикацию после проверок. Повторно спрашивать об этих этапах не требуется. Дополнительные разрешения Google и платные сервисы требуют отдельного конкретного согласования.

## Реализовано в ветке feat/card-images-motion

- Изображения вопроса и ответа, включая сторону только с изображением; прежние ID и SRS сохраняются.
- Закрытые неизменяемые вложения в существующем постоянном хранилище PostgreSQL (отдельные документы); локальные JSON только для разработки.
- Чтение по серверной сессии: собственные загрузки, ссылки своих карточек/корзины/спорных версий либо доступная публикация. Ссылки на чужие неопубликованные картинки отклоняются при изменении карточки.
- Исходные JPEG/PNG/WebP до 2 МБ, до 16 МП; проверка декодером, удаление метаданных, уменьшение до 2400 px, преобразование WebP. Лимит загруженных изображений профиля 100 МБ. Неиспользуемые загрузки пока не очищаются автоматически.
- Копия получает новый ID карточки и ссылки на неизменяемые изображения. Замена ссылки в копии не меняет оригинал или публикацию.
- Загрузка из формы, отдельное увеличение (в том числе поверх редактора без потери формы), показ ответа отдельной кнопкой, полный ID с копированием.
- Цвета оценок и счётчиков, короткие переходы, завершение со ступенями, настройка отключения; системный reduced motion учитывается.
- Текущий текстовый Google-импорт сохраняет существующие изображения карточки.

Реальный браузер, отдельный локальный профиль: изображение вопроса и ответа, переворот, увеличение, Escape и возврат фокуса, оценка и счётчик, отключение анимации, загрузка файла через системный выбор, увеличение поверх формы и сохранение замены. Светлая и тёмная тема осмотрены; фактическая ширина 375 px, scrollWidth 375 px. Полный мобильный регресс и реальные два Google-профиля ещё не выполнены.
