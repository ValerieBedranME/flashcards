## Дополнительные проверки защиты

OAuth привязан к профилю, использует одноразовый state и PKCE; повтор callback не получает доступ. Тесты подтверждают шифрование токенов и отсутствие секретов в bootstrap. Старые изменяющие API не позволяют обойти проверки версий для подключённой таблицы. Выбор спорной правки содержит отпечаток увиденных вариантов; новая правка требует заново посмотреть варианты.

Новые импортированные строки не попадают в занятие до подтверждения ID в таблице. Повтор импорта после изменения строки не оставляет лишнюю карточку. Добавление позже ещё одной строки с таким же текстом создаёт новую карточку; одинаковый текст не считается идентификатором. Взятую копию можно дополнить строками в Sheets с сохранением исходного автора; неоднозначные названия наборов вызывают явную ошибку.

## Что осталось до выпуска

1. Завершить Google OAuth после отдельного разрешения на доступ к файлам и пройти реальные сценарии с таблицами двух пользователей. Условия сервиса уже приняты.
2. Проверить новый протокол снимков на настоящем Google: изменение ячейки после контрольного чтения, потерю ответа, изменение после потерянного ответа, сортировку и восстановление. Проверить новые кнопки восстановления в браузере. По имитации гарантии внешнего API не объявлять подтверждёнными.
3. Завершить настройки внешнего доступа Google для одногруппников и параметры хостинга, оставшиеся интерфейсные проверки; затем выпуск и T24. Перед выпуском сделать свежий backup, если рабочие данные изменились.

Подробности настройки: [Google и выпуск](google-setup.md). Непроверенные части не считаются пройденными.

Дополнительно проверены короткая аренда создания таблицы (повторный запрос не создаёт второй файл), сохранение ID после ошибки настройки и повторное использование этого файла.

Последний браузерный повтор: конфликт автоматически открывает два варианта, выбор проверяется по отпечатку версии и сохраняется; ошибок console нет. В светлой теме у получателя сохранено «Не уверен: 1», у автора осталось «Знаю: 1». Тестовая смена color-scheme сделана только в локальном скрипте предпросмотра, настройки пользователя не изменялись.

Проверки 13 сентября: 53 локальных теста прошли; 3 отдельных теста PostgreSQL прошли за 50,8 с. Сохранение состояния повтора при 503 и откат неожиданного 500 подтверждены настоящими транзакциями. Восстановление после перемещения строк сохраняет прежний файл, подтверждённые личные ID и SRS; повтор не создаёт лишнего задания. Ключ резервной копии хранится отдельно от зашифрованного файла, вне Git.
