# Карточки — Анатомия

Веб-приложение для изучения анатомии и физиологии человека по карточкам (flashcards) с системой интервальных повторений (SRS).

Создано для студентов медицинского направления (специальность «лечебное дело» / фельдшер).

## Возможности

- Регистрация и вход по имени + паролю
- Общая база карточек (вопрос → ответ) с темами
- Личные карточки: добавление, редактирование, удаление
- Система интервальных повторений (SRS) по принципу Лейтнера:
  - «Знаю» → интервал удваивается
  - «Не уверен» → интервал уменьшается вдвое
  - «Не знаю» → сброс на сегодня
- Восстановление пароля по email (опционально)

## Технологии

- Python 3 + Flask (сервер)
- HTML/CSS/JS (одностраничный фронтенд, без сборки)
- Хранение данных в JSON-файлах

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Приложение откроется на `http://localhost:8081`.

## Запуск на хостинге (Gunicorn)

```bash
pip install -r requirements.txt
gunicorn app:app --bind 0.0.0.0:8081
```

Порт можно задать через переменную окружения `PORT`.

## Настройка отправки писем (восстановление пароля)

По умолчанию отправка писем **отключена**. Чтобы включить, задайте переменные окружения:

- `EMAIL_ENABLED=1` — включить отправку
- `EMAIL_PYTHON` — путь к python-интерпретатору с доступом к Gmail API
- `EMAIL_SCRIPT` — путь к скрипту отправки (google_api.py)

## Структура данных

- `cards.json` — общая база карточек (видна всем пользователям)
- `users.json` — аккаунты пользователей (создаётся автоматически, **не публикуется**)
- `reset.json` — коды восстановления пароля (создаётся автоматически, **не публикуется**)
